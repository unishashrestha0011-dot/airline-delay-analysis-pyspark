# Airline Delay Analysis using PySpark

## Overview
This project analyses airline delay data using Apache Spark and PySpark.

## Tasks Completed
- Data preprocessing
- Null value handling
- Outlier handling
- Delay trend analysis
- Airline comparison
- Airport delay analysis
- Delay cause analysis
- Seasonal delay analysis

## Tools Used
- Python
- PySpark
- Apache Spark
- Pandas
- Matplotlib
- Google Colab

## Dataset
The dataset is not included in this repository because it exceeds GitHub's upload size limit.
